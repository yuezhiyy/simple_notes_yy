# 桌面备忘（simple_notes_yy）

贴在 Windows 屏幕右缘的小备忘。平常只露出一个黄点，点一下拉出待办列表；左侧圆圈切换「待办 / 正在做 / 完成」，拖动手柄调顺序，删掉会归档到本地 CSV，不真删。

## 环境

- Windows
- Python 3（官方安装包即可，需带 **tkinter**，一般默认就有）
- **不需要** `pip install` 任何第三方库

命令行确认：

```bat
py -3 -c "import tkinter; print('ok')"
```

## 启动

1. 下载或 clone 本仓库
2. 双击 `启动桌面备忘.bat`

或在仓库目录执行：

```bat
pyw -3 desk_notes.pyw
```

启动后屏幕右侧中间会出现黄色圆点。同一时间只会跑一份。

## 怎么用

| 操作 | 说明 |
| --- | --- |
| 左键点黄点 | 展开 / 收起备忘面板 |
| 底部输入框 + 回车 | 新增一条 |
| 左侧圆圈 | 状态循环：待办 → 正在做 → 完成（同时只能有一条「正在做」） |
| 左侧六点手柄 | 按住上下拖动，调整顺序 |
| 右侧垃圾桶 | 归档（写入 CSV，带日期，不真删） |
| 面板底部「归档」 | 查看已归档，可还原 |
| 右键黄点，或点右上角 `···` | 打开菜单：查看归档 / 打开 CSV / 打开数据文件夹 / 退出 |
| `Esc` | 收起面板；在归档页则返回备忘 |

## 数据存在哪

本地文件：

```text
data/notes.csv
```

用记事本、Excel、WPS 都能直接打开。列包括：内容、状态、顺序、写下时间、更新时间、归档时间。

`data/` 已在 `.gitignore` 里，个人备忘不会进 Git。

## 开机自启（可选）

给 `启动桌面备忘.bat` 建快捷方式，放进：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

## 说明

- 窗口置顶，不占任务栏
- 删掉 = 归档到 CSV，可在「归档」里还原
- 若启动无反应，看同目录 `data/error.log`
